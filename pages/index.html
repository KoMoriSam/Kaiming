他说：“开明，清楚；准确。”——这就是中文标点。
01 · Half width

「开」「明」

括号、引号和顿逗类标点采用半字宽，正文节奏更紧凑。

02 · Compression

真的？！

连续句末标点压缩排列，保留强调，也避免空白松散。

03 · Ligature

上篇——下篇

双破折号形成连续的二字宽连字，与正文版心自然衔接。

Use on the web

一行引入，按需回退。

CSS 内置了精确的 unicode-range，因此只会下载并替换所包含的中文标点。 

@import url("./kaiming-punctuation-variable.css");

article {
  font-family: "Kaiming Punctuation Sans",
    "Noto Sans SC", sans-serif;
  font-weight: 100 900;
}
